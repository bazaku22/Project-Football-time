PROJECT FOOTBALL TIME — รุ่นเริ่มต้น

ไฟล์:
- index.html: แอปต้นแบบแบบ responsive
- manifest.webmanifest: ข้อมูลสำหรับติดตั้งเป็น PWA
- sw.js: cache เบื้องต้นสำหรับใช้งานออฟไลน์หลังโหลดครั้งแรก

ข้อจำกัด:
- นี่คือ PWA prototype ไม่ใช่ APK และยังไม่เชื่อม API/ฐานข้อมูลออนไลน์
- ข้อมูล 6 คู่เป็นข้อมูลทดสอบจากบันทึกบทสนทนา
- เวลาแข่งขันและผลจริงที่ยังไม่ยืนยันจะแสดงว่าไม่ยืนยัน
- ก่อนใช้งานจริงต้องโฮสต์ผ่าน HTTPS เพื่อให้ติดตั้ง PWA ได้
- การสร้าง APK จาก PWA ต้องนำ URL ที่โฮสต์แล้วไปใช้เครื่องมือเช่น PWABuilder หรือ build ด้วย Capacitor/Android Studio
- เนื่องจากมีเพียงมือถือ Android การ build APK อาจทำได้ผ่านบริการ build บนคลาวด์ แต่ขั้นตอนตั้งค่าและ signing ต้องทำเพิ่มเติม

เริ่มทดสอบ:
1. อัปโหลดไฟล์เหล่านี้ไปยัง GitHub repository
2. เปิด GitHub Pages ให้เผยแพร่จาก branch หลัก
3. เปิด URL ที่ได้ใน Chrome บน Android
4. เมนู Chrome > เพิ่มลงในหน้าจอหลัก / ติดตั้งแอป

นี่เป็นต้นแบบเพื่อทดสอบหน้าตาและการนำทาง ไม่ใช่แหล่งข้อมูลราคาสดหรือคำแนะนำการเดิมพัน
