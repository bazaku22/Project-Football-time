PROJECT FOOTBALL TIME — Personal Football Analytics

สถานะ:
- แอป PWA สำหรับใช้งานส่วนตัว เน้นสถิติฟุตบอลและการวิเคราะห์การแข่งขัน
- ครอบคลุม 5 ลีก: Premier League, La Liga, Bundesliga, Serie A และ Ligue 1
- มีข้อมูลโปรแกรม/ผลการแข่งขัน/ตารางคะแนน และเครื่องมือวิเคราะห์ทีม
- มี Team Strength, Poisson Match Probability, การประเมินความแม่นยำ และ Probability Calibration
- มีฐานข้อมูลนักเตะส่วนตัว 156 รายการใน Supabase (ข้อมูลเดิมต้องคงอยู่)
- รองรับการบันทึกข้อมูลทดสอบและประวัติการทำนาย

แนวทางพัฒนาปัจจุบัน:
- Personal-use / Simple Mode (Option A): เน้นความเสถียร ความถูกต้อง และดูแลง่าย
- ไม่ขยายระบบสถิตินักเตะหลายผู้ให้บริการในระยะนี้
- ไม่เพิ่ม API provider, ความถี่เรียก API หรือค่าใช้จ่ายโดยไม่ได้รับอนุญาต
- Wyscout, Impect, Reep, OpenPlay, StatsBomb และ API Ninjas เป็นงานทดลอง/เอกสารอ้างอิงเท่านั้น ยังไม่ใช่แหล่งข้อมูล production
- เป้าหมายค่าใช้จ่ายต่อเดือน 0 บาท โดยไม่มีบริการแบบชำระเงินหากผู้ใช้ยังไม่อนุมัติ

ข้อกำหนดการรักษาข้อมูล:
- ห้ามลบหรือเปลี่ยน Local Storage key `pft_matches_v1`
- รักษารายการทดสอบ #001–#011 และประวัติ prediction snapshots/calibration
- รักษาฐานข้อมูลนักเตะ 156 รายการเดิม
- API keys ต้องอยู่ใน GitHub Secrets หรือการตั้งค่าฝั่ง server เท่านั้น ห้ามใส่ใน client code

ข้อจำกัด:
- ข้อมูลการแข่งขันขึ้นอยู่กับแหล่งข้อมูลและโควตา API ที่ตั้งค่าไว้
- เมื่อข้อมูลไม่พร้อมหรือยังไม่ยืนยัน ต้องแสดงสถานะตามจริง ไม่คาดเดาหรือสร้างข้อมูลแทน
- แอปนี้เป็นเครื่องมือสถิติและวิเคราะห์กีฬา ไม่ใช่บริการรับพนันหรือวางเดิมพัน
